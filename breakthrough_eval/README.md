# HNG Frontier Breakthrough Evaluation

This directory is the evidence workspace for the breakthrough program. The immutable release baseline is commit `e57db1b1e92329e9b8f2b173be9a506d2b898da8` (`v0.7.0rc1`). Development continues on later commits, but baseline results are always executed from a detached worktree at that exact commit.

Evidence classes must remain distinct:

- **real**: observed production assistant or user interactions;
- **public**: official external benchmark data and protocol;
- **synthetic**: generated tasks, vectors, users, corruptions, or simulated assistants;
- **literature**: results reported by another paper or repository and not reproduced here.

No unavailable system is counted as defeated. No synthetic assistant is described as the real HDC assistant. Architecture changes may follow only an observed failure with a general hypothesis and holdout regression.

## Reproduction

The baseline runner records stdout, stderr, duration, return code, exact command, environment, and copied machine artifacts:

```powershell
C:\Python310\python.exe breakthrough_eval\scripts\freeze_baseline.py `
  --baseline-root C:\tmp\hng-breakthrough-baseline-e57 `
  --output-root breakthrough_eval\baseline_070 `
  --batch core
```

Additional batches are `gauntlets`, `public`, `providers`, and `10m`. Batches are resumable: a completed command is not silently overwritten. Results generated by a rerun receive a timestamped revision while the first result remains preserved.

The QMSum public batch additionally requires `--qmsum-jsonl` pointing to the official test JSONL. External datasets are not committed to this repository.

## Current resource boundary

The repository includes synthetic HDC assistant benchmarks, adapters, QMSum, and the governed-memory implementation. It does not include the user's production HDC interpreter, real interaction traces, LLM credentials, or downloaded LongMemEval-V2/LoCoMo-Plus/PersonaMem-v2 datasets. Those gates remain `BLOCKED_EXTERNAL` until the required resource is actually available; they are never substituted with oracle labels or synthetic vectors.
